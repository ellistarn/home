# Maintain .AGENTS.md

`.AGENTS.md` is a map of the repository. An agent reading it should understand what the repo
contains, where things live, and how they relate — without exploring the codebase. If an agent
still has to search to understand what's here, the document failed. Implementation details belong
in source files, not here.

It is regenerated from scratch every time — never patched, never carried forward.

## Delegation

This skill is context-heavy. Use the Task tool with `subagent_type: "explore"` and prompt: "Load
the `maintain-agentsmd` skill using the skill tool and execute its full process."

## Constraints

- Do NOT read the existing `.AGENTS.md`. Derive all output from source files only.
- Use the **Write** tool to produce `.AGENTS.md`. Never use Edit — full replacement only.
- Every factual claim must trace to a specific tracked file.

## Process

1. Run `git ls-files` for the authoritative list of tracked files.
2. Read tracked files and extract what future agents would need to know.
3. Write `.AGENTS.md` with this header:
   ```
   <!-- GENERATED FILE — do not hand-edit. Regenerated by the maintain-agentsmd skill. -->
   ```
4. Spot-check the output against source files. If anything is wrong, rewrite — do not patch.
