# Maintain AGENTS.md

`README.md` is for humans. `AGENTS.md` is for agents. This skill produces only `AGENTS.md` — a
structured reference that lets an agent understand what the repo contains, where things live, and
how they relate without exploring the codebase. If an agent still has to search after reading it,
the document failed. Do not modify `README.md`. Do not include implementation details that belong
in source files.

It is regenerated from scratch every time — never patched, never carried forward.

## Delegation

This skill is context-heavy. Use the Task tool with `subagent_type: "explore"` and prompt: "Load
the `reconcile-agents-md` skill using the skill tool and execute its full process."

## Output filename

The default output filename is `AGENTS.md`. When running in the home directory repo (`~`), use
`.AGENTS.md` instead — the dot-prefix prevents agent tools from cascading it into nested projects
via upward directory traversal.

## Constraints

- Do NOT read the existing `AGENTS.md`. Derive all output from source files only.
- Use the **Write** tool to produce the output file. Never use Edit — full replacement only.
- Every factual claim must trace to a specific tracked file.

## Process

1. Determine the output filename (see "Output filename" above).
2. Run `git ls-files` for the authoritative list of tracked files.
3. Read tracked files and extract what future agents would need to know.
4. Write the output file with this header:
   ```
   <!-- GENERATED FILE — do not hand-edit. Regenerated by the reconcile-agents-md skill. -->
   ```
5. Spot-check the output against source files. If anything is wrong, rewrite — do not patch.
